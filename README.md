# eye-corrector
КОРРЕКТОР ЗРЕНИЯ — версия для браузера (HTML/JS). Перенос программы «Корректор зрения» (Центр Биоинформационных технологий, 2007) из формата Flash (SWF) в обычную веб-страницу. Flash и эмуляторы не нужны.

Корректор зрения - это компьютерная программа, созданная по уникальной методике и предназначенная для восстановления зрения, улучшения зрения, снятия усталости глаз, предотвращения ухудшения зрения. В программе используются специальные упражнения для зрения и SIRDS-картинки.
В результате работы с программой улучшается глазное кровообращение, укрепляются глазные мышцы, развивается аккомодативная способность глаз, которая, в свою очередь, способствует улучшению питания глазного нерва, снятию спазма аккомодации, повышению остроты зрения.
Программа не имеет противопоказаний и рекомендуется для ежедневного использования.



КАК ЗАПУСТИТЬ
  Откройте файл index.html в браузере (двойной клик). Работает офлайн,
  в Safari, Chrome и Firefox. Звук включится после первого нажатия кнопки.

УПРАВЛЕНИЕ
  Мышь            — кнопки, как в оригинале
  Пробел / клик   — «вижу трёхмерное изображение» (экраны SIRDS-картинок)
  F               — полный экран
  Esc             — вернуться из упражнения к его описанию (нового в оригинале не было)

ЧТО ВНУТРИ
  index.html, css/, js/app.js  — логика программы (восстановлена из ActionScript оригинала)
  js/data.js                   — экраны, тексты, траектории глаза
  img/    — 29 стереокартинок (исходные JPEG, без пережатия)
  svg/    — оформление и кнопки (векторные, из оригинала)
  eye/    — рисунки глаза и стрелок
  audio/  — звуковые сигналы упражнений

ОТЛИЧИЯ ОТ ОРИГИНАЛА
  * Упражнение «аккомодация»: в оригинале из-за ошибки в скрипте каждый второй щелчок
    пропускал анимацию моргания и число картинок ограничено. Здесь щелчок всегда
    показывает моргание и новую картинку, ограничения нет. Время упражнения прежнее (55 с).
  * В оригинале картинка №6 отсутствовала (пустой экран) — здесь она не показывается.
  * Добавлены Esc и полноэкранный режим (F).
  * Кнопка «Выход» показывает экран «Программа закрыта» (браузер не даёт закрыть вкладку скриптом).

Авторские права на программу и материалы принадлежат её разработчикам; версия сделана для личного использования.
